# Campus Lost-and-Found Platform

A web-based platform designed to help students report, search for, and recover lost and found items within a college campus.

## Team Members

- Bhuvanesh D – Backend / Development
- Adarsh Sudheer Gadagin – Frontend / Development
- Abhinav Prassad – UI/Design, Development & Presentation

## Proposed Features

- Report lost items
- Report found items
- Search and filter items
- View item details
- Contact the person who reported an item
- Update item status

## Proposed Technology Stack

- React.js
- Node.js
- Express.js
- Firebase Firestore
- Firebase Authentication
- Vercel

## Project Status

Initial planning and problem definition completed.
